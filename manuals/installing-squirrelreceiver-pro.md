# Installing SquirrelReceiver Pro

SquirrelReceiver Pro is the Microsoft Store version of SquirrelReceiver.

It includes Wi-Fi live view and the wired USB live view path. Wired mode is the main reason to choose Pro: it is cleaner than Wi-Fi, usually has lower latency, and charges the goggles while connected.

Install it here: [SquirrelReceiver Pro on Microsoft Store](https://apps.microsoft.com/detail/9p95mhs1678g)

Price: **USD $19.99**

## Install

Purchase and install SquirrelReceiver Pro through the Microsoft Store.

There is no separate activation workflow. Licensing is handled through the Microsoft Store and can be checked in SquirrelReceiver settings.
